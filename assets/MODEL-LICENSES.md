[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/) and downloaded through [Poly Pizza](https://poly.pizza).
CC0 asks for nothing in return; the credit below is courtesy.

Most come from the [Ultimate Monsters bundle](https://poly.pizza/bundle/Ultimate-Monsters-Bundle-5oyGWAmOB6).

The game loads each model at run time and falls back to its own procedural giant if a model cannot be loaded,
so the game still works offline or with the files removed.
