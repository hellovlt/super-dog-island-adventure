# Super Dog 4.0 - Campaign Playtest Report

Date: September 18, 2026. Game URL: http://localhost:5173/.

The English update passed **115 tests with zero failures**. This includes a regression check for interface copy, HTML language, guides, and all ten secret events.

## English update verification

The secret dialog now displays “Secret found!”, the Mushroom Tea Party story, the album count, and “Keep exploring” in English. Chrome checks covered the secret album, the five-world menu at desktop and 391 CSS pixels, and the victory transition to Crystal Winter. The classic game's interface and help were also checked in English. No browser console errors were recorded in these QA pages. Existing player progress was preserved. The English Word guide was regenerated and its document text checked.

## Simulation coverage

- Complete first-world playthroughs on all difficulties at 15/30/60/120 updates per second; the four new worlds at 15/60. Scenarios use normal movement and action inputs.
- Sequential unlocks, revisiting worlds, separate collections, old save migration, and completing the fifth world.
- Ten secrets: E interaction, one-time discovery, and optional progression.
- Giant body collisions, camera orbit checks, lava, and unobstructed pickups and checkpoints.
- Safe starts: 30 idle seconds on Hard in each new world.
- Existing 3D physics and classic 2D regression tests.

## Chrome checks

On an isolated page with separate storage, checks covered boss presentation, sideways movement, discovering Mushroom Tea Party with E, its dialog, the album entry, the victory dialog, and transition to Crystal Winter. The victory dialog used a prepared scene; this was not a manual full-level playthrough.

The mushroom, winter, and volcano worlds and the Cloud Emperor were visually inspected. The battle camera frames the giant bosses. At 391 CSS pixels, the menu and album have no horizontal overflow and their controls remain available.

The normal game loaded a completed first-world save on Hard and unlocked Mushroom Kingdom without resetting progress. New adventure was tested in the QA profile and returned to the first world. Version 4 uses separate storage so older tabs cannot overwrite the new campaign.

## Fixes found during playtesting

The battle camera zooms out and stays anchored to the player, avoiding a target inside the giant body. Boss geometry participates in camera obstruction checks. Secret-dialog encoding was repaired. Enemies were moved away from spawn points. The classic-game link follows page flow on narrow screens.

## Limits

Simulation tests are not device frame-rate benchmarks. Every world was not played manually from start to finish. Mobile checks used a narrow Chrome viewport, not a physical phone. The game is local and has not been published to a public host.
