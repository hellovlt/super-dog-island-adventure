# Super Dog 3.1 - Historical Playtest Report

Date: September 17, 2026. This report covers the earlier single-island release.

All 76 tests passed. Coverage included movement, double jumps, dashes, collisions with buildings and props, cages, camera obstruction, line of sight, checkpoints, damage, difficulty, saves, and the classic 2D game.

The rescue route and boss battle were completed with normal simulation inputs on Easy, Normal, and Hard at 15, 30, 60, and 120 updates per second. These rates test simulation behavior, not device rendering performance.

Isolated Chrome scenes were used to inspect movement, collisions, rescue prompts, checkpoints, boss states, retry behavior, and mobile layout. QA used separate browser storage and preserved the normal game save. Later campaign changes are documented in the version 4 report.
